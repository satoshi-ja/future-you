🎨 Part 1: デザイン哲学 (Design Philosophy)
1.1 コアプリンシプル
【Apple的思考】
❶ Clarity（明瞭性）
  → ユーザーは迷わない。すべてが一目瞭然。
  
❷ Deference（控えめさ）  
  → コンテンツが主役。UIは黒子に徹する。
  
❸ Depth（奥行き）
  → 視覚的な階層で情報に優先順位をつける。

【追加原則】
❹ Storytelling First
  → データではなく、人の物語を語る
  
❺ Emotional Connection  
  → 理性ではなく、感情に訴える
1.2 ミニマリズムの定義
【排除すべき要素】
✗ 装飾的なアイコン
✗ 過剰なボーダーライン
✗ 不要な背景色の切り替え
✗ 複雑なグラデーション
✗ 多色使い（3色以内に制限）

【残すべき要素】
✓ 大胆なタイポグラフィ
✓ 高品質なビジュアル（写真・動画）
✓ 十分な余白
✓ 明確な階層構造
✓ 意味のあるアニメーション

6.3 スクロールアニメーション実装
javascript// ============================================
// SCROLL ANIMATIONS - Intersection Observer API
// ============================================

const observerOptions = {
  root: null,
  rootMargin: '0px',
  threshold: 0.1
};

const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.classList.add('is-visible');
      // 一度表示したら監視を解除（パフォーマンス向上）
      observer.unobserve(entry.target);
    }
  });
}, observerOptions);

// 監視対象の要素を取得
const animateElements = document.querySelectorAll('.animate-on-scroll');
animateElements.forEach(el => observer.observe(el));
css/* アニメーション対象のCSS */
.animate-on-scroll {
  opacity: 0;
  transform: translateY(30px);
  transition: opacity var(--duration-slow) var(--ease-apple),
              transform var(--duration-slow) var(--ease-apple);
}

.animate-on-scroll.is-visible {
  opacity: 1;
  transform: translateY(0);
}

/* 段階的に表示（Stagger効果） */
.animate-on-scroll:nth-child(1) { transition-delay: 0ms; }
.animate-on-scroll:nth-child(2) { transition-delay: 100ms; }
.animate-on-scroll:nth-child(3) { transition-delay: 200ms; }
